The 4 Core Cases (A1–A2 Foundation)

1. Nominative (*Mianownik*) — The Subject / The Actor

System Role: The default dictionary form. The entity actively performing the verb or existing as the core topic.

Question Trigger: Kto? Co? (Who? What?)

Code Example: Kot spał. (The cat slept.)

2. Accusative (*Biernik*) — The Direct Object / Target

System Role: The direct receiver of an action. Triggered by transitive verbs or movement into spaces (*w, na*).

Question Trigger: Kogo? Co? (Whom? What?)

Code Example: Mam kota. Widzę książkę. (I have a cat. I see a book.)

3. Genitive (*Dopełniacz*) — The Missing, The Owner, or The Boundary

System Role: Triggered during negation (*nie*), ownership (of X), quantities over 5, and boundary prepositions (*do, bez, od*).

Question Trigger: Kogo? Czego? (Whom? Of what?)

Code Example: Nie mam czasu. Idę do sklepu. (I don't have time. I'm going to the store.)

4. Locative (*Miejscownik*) — The Container / Location

System Role: Always locked behind prepositions of static location, primarily w (in) and na (on/at).

Question Trigger: O kim? O czym? / Gdzie? (About whom? About what? / Where?)

Code Example: Kot jest w domu. (The cat is in the house.)

The 3 Advanced Cases (B1–B2 System Completion)

5. Instrumental (*Narzędnik*) — The Tool / Companion

System Role: Denotes the tool used to accomplish an action (narzędzie = tool), accompaniment using z (with), or professional identity after być.

Question Trigger: Kim? Czym? (With whom? With what?)

Code Example: Piszę długopisem. Idę z przyjaciółmi. Jestem inżynierem. (I write with a pen. I go with friends. I am an engineer.)

6. Dative (*Celownik*) — The Recipient / Target of Benefit

System Role: Used for the indirect object—the person or thing receiving something (giving, helping, telling).

Question Trigger: Komu? Cemu? (To whom? To what?)

Code Example: Daję książkę bratu. Pomagam siostrze. (I give a book to the brother. I help the sister.)

7. Vocative (*Wołacz*) — The Direct Address

System Role: Strictly used when directly calling out to or addressing a person, title, or pet. Holds no grammatical sentence dependency.

Question Trigger: None (Pure direct call)

Code Example: Cześć, Anno! Panie doktorze! (Hi, Anna! Doctor!)
