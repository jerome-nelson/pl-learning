Level A1: Core Productive Patterns

A1 Type 1: -ować / -ywać Conjugation (The -uję Pattern) CEFR A1 • Highly Productive

Primary Ending Pattern: Infinitives ending in -ować drop the suffix and insert -uj- before all present-tense endings (e.g., -uję, -ujesz).

Key Rule: Highly predictable and regular. Serves as the template for most international loanwords and professional verbs.

Present / Czas Teraźniejszy (pracować)

ja: pracuję
ty: pracujesz
on/ona/ono: pracuje
my: pracujemy
wy: pracujecie
oni/one: pracują

Past / Czas Przeszły (pracować)

ja (m/f): pracowałem / pracowałam
on / ona / ono: pracował / pracowała / pracowało
my (m-pers/oth): pracowaliśmy / pracowałyśmy
wy (m-pers/oth): pracowaliście / pracowałyście
oni / one: pracowali / pracowały
A1 Type 2: -iæ / -yæ Conjugation (The -isz / -ysz Pattern) CEFR A1 • Standard Conjugation I

Primary Ending Pattern: Infinitives ending in -ić or -yć. Take -ę for ja and -isz / -ysz for ty.

Key Rule: Frequently features light consonant softening (palatalization) in the 1st person singular (e.g., mówić → mówię).

Level A2: Expanded Patterns & Suffix Shifts

A2 Type 1: -eæ Conjugation (The -esz Pattern) CEFR A2 • Conjugation II

Primary Ending Pattern: Infinitives ending in -eć (frequently states of mind or senses like rozumieć, widzieć). Uses -esz for ty.

Key Rule: Stem vowels often shift between infinitive and conjugated forms (e.g., root vowel length or nasal adjustments).

ty: rozumiesz
on/ona/ono: rozumie
my: rozumiemy
wy: rozumiecie
oni/one: rozumieją

oni / one: rozumieli / zrozumiały
A2 Type 2: -nąæ Conjugation (The -nę / -nisz Pattern) CEFR A2 • Ingressive Actions

Primary Ending Pattern: Verbs ending in -nąć, indicating momentary, sudden, or single actions. Uses -nę for ja and -nisz for ty.

Key Rule: In the masculine past tense, the -ną- segment frequently drops out entirely (e.g., osiągnąć → osiągnął, but gasnąć → gasł).

Level B1: Complex Endings, Consonant Alternations & Irregulars

B1 Type 1: Complex Consonant Alternations (-œæ / -æ Verbs) CEFR B1 • Deep Stem Shifts

Primary Ending Pattern: Infinitives ending in -ść or -źć (e.g., niesć, gryźć) where the underlying root consonant changes dramatically across personal forms.

Key Rule: Consonants like s/sz, d/dz, or velars undergo historic mutations. For example, jeść shifts internal consonants completely: jem, jesz, je... jedzą.

Present / Czas Teraźniejszy (jeść - to eat)

ja: jem
ty: jesz
on/ona/ono: je
my: jemy
wy: jecie
oni/one: jedzą

Past / Czas Przeszły (jeść)

ja (m/f): jadłem / jadłam
on / ona / ono: jadł / jadła / jadło
my (m-pers/oth): jedliśmy / jadłyśmy
wy (m-pers/oth): jedliście / jadłyście
oni / one: jedli / jadły
B1 Type 2: Highly Irregular / Athematic Core Verbs (byæ, mógæ) CEFR B1 • Exceptional Paradigms

Primary Ending Pattern: Verbs with contractions or velar past-tense forms (like móc → mogę, może) that break standard suffix classifications entirely.

Key Rule: Móc drops the infinitive -c and mutates velars into fricatives (g → ż or g → g) before personal endings. Past tense uses unusual roots (mógł).
