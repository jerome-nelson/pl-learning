The 4 Core Cases / Places (A1–A2 Foundation)

1. Mianownik / Nominative (The Subject / The Actor Place)

System Role: The default dictionary form. The entity actively performing the verb or existing as the core topic.

Question Trigger: Kto? Co? (Who? What?)

Code Example: Stary kot spał. (The old cat slept.)[cite: 2]

"Singular: Can You Imagine Eggs?" (C[onsonant] - Y - I - E)

"Plural: Owie, Your Iguanas Ate..." (Owie - Y/I - A)

Adjective Mnemonic — "Young Athletes Earn Yearly Easily" (m -y/-i, f -A, n -E, virile pl -i/-Y, non-virile pl -E)

2. Biernik / Accusative (The Direct Object / Target Place)

System Role: The direct receiver of an action. Triggered by transitive verbs or movement into spaces (*w, na*).

Question Trigger: Kogo? Co? (Whom? What?)

Code Example: Mam małego kota. Widzę ciekawą książkę. (I have a small cat. I see an interesting book.)[cite: 2]

"Singular: Constants Always Eat Identically" (Constant - A - Ę - No Change)

"Plural: Owls Inspect Identical" (ÓW - I - No Change)

Adjective Mnemonic — "Every Alive Guy Eats, Yielding Easily" (m-animate -EGO, m-inanimate = Nom., f -Ą, n -E; virile pl -YCH/-ich, non-virile pl -E)

3. Dopełniacz / Genitive (The Missing, The Owner, or The Boundary Place)

System Role: Triggered during negation (*nie*), ownership (of X), quantities over 5, and boundary prepositions (*do, bez, od*).

Question Trigger: Kogo? Czego? (Whom? Of what?)

Code Example: Nie mam wolnego czasu. Idę do nowego sklepu. (I don't have free time. I'm going to the new store.)[cite: 2]

"Singular: A Useless Yellow Apple" (A - U - Y - A)

"Plural: Old Igloos Collapse" (ÓW - Zero/Ø - Zero/Ø)

Adjective Mnemonic — "Elegant Guys Enjoy Everything, Hey!" (m/n -EGO, f -EJ, all-gender pl -YCH/-ich)

4. Miejscownik / Locative (The Container / Location Place)

System Role: Always locked behind prepositions of static location, primarily w (in) and na (on/at).

Question Trigger: O kim? O czym? / Gdzie? (About whom? About what? / Where?)

Code Example: Kot jest w starym domu. (The cat is in the old house.)[cite: 2]

"Singular: Every Unusual Elephant Eats" (E - U - E - E)

"Plural: All Cats Howl" (Ach)

Adjective Mnemonic — "Young Men Enjoy Hiking" (m/n -YM/-im, f -EJ, all-gender pl -YCH/-ich)

The 3 Advanced Cases / Places (B1–B2 System Completion)

5. Narzędnik / Instrumental (The Tool / Companion Place)

System Role: Denotes the tool used to accomplish an action (narzędzie = tool), accompaniment using z (with), or professional identity after być.

Question Trigger: Kim? Czym? (With whom? With what?)

Code Example: Piszę czarnym długopisem. Jestem dobrym inżynierem. (I write with a black pen. I am a good engineer.)[cite: 2]

"Singular: Every Aunt Enjoys" (Em - Ą - Em)

"Plural: Always Make It" (Ami)

6. Celownik / Dative (The Recipient / Target of Benefit Place)

System Role: Used for the indirect object—the person or thing receiving something (giving, helping, telling).

Question Trigger: Komu? Czemu? (To whom? To what?)

Code Example: Daję książkę młodemu bratu. Pomagam chorej siostrze. (I give a book to the young brother. I help the sick sister.)[cite: 2]

"Singular: Owls Usually Eat Under" (Owi - U - E - U)

"Plural: Only Owls Moo" (Om)

7. Wołacz / Vocative (The Direct Address Place)

System Role: Strictly used when directly calling out to or addressing a person, title, or pet. Holds no grammatical sentence dependency.

Question Trigger: None (Pure direct call)

Code Example: Cześć, droga Anno! Panie doktorze! (Hi, dear Anna! Doctor!)[cite: 2]

"Singular: I Use Old Icons" (Ie/E - U - O - Iu - Identical)

"Plural: Identical To Nominative" (Identical)

Adjective Mnemonic — "Adjectives Just Nominate" (all adjective forms match the Nominative: m -y/-i, f -a, n -e, pl as Nom.)
