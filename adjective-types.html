What is Adjective Agreement in Polish?

Unlike English, Polish adjectives change their endings to precisely match the gender, case, and number of the noun they modify. Dictionary forms are always listed in the Masculine Nominative Singular (e.g., nowy - new).

1. Hard-Stem vs. Soft-Stem Adjectives

Adjectives split into two major stem groups which dictate their suffix choices across all cases:

Stem Category Base Endings Feminine (-a) / Neuter (-e) Pattern Examples
Hard-Stem Ends in a hard consonant + -y Fem: -a, Neut: -e nowy (new), stary (old)
Soft-Stem Ends in a soft consonant + -i Fem: -a, Neut: -e (with soft stem adjustments) tani (cheap), cisi / cichy variants

2. Nominative Case Gender Matrix (Singular)

Gender / Rodzaj Hard-Stem Ending Soft-Stem Ending Example (Hard / Soft)
Masculine / Męski -y / -i (after k, g) -i nowy dom / tani dom
Feminine / Żeński -a -a nowa książka / tania książka
Neuter / Nijaki -e -ie nowe okno / tanie okno

3. Degrees of Comparison

Degree Formation Rule Example
Comparative (Wyższy) Add -szy / -niejszy to the stem nowszy (newer), cieplejszy (warmer)
Superlative (Najwyższy) Prefix naj- to the comparative form najnowszy (newest), najcieplejszy (warmest)
